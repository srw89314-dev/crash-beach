# Privacy

Crash Beach v0.50 is a static browser game.

- It does not create accounts.
- It does not include analytics, advertising, tracking pixels, or third-party network requests.
- Continue-mode saves, preferences, intro-seen state, and best-run records are stored only in the browser's `localStorage` for the site where the game is played.
- Clearing that site's browser data deletes those local records.
- Uploading the build to a host such as itch.io or Netlify may cause that host to process ordinary web-server logs under its own privacy policy; the game code does not read or transmit those logs.

Privacy statement reviewed against the v0.50 candidate on 2026-10-22.
